# PunchPrint UI

这个小工具用于在打印平台上手动画外框，并根据外框生成 PunchPrint EPI 网格 G-code。

## 使用

直接用浏览器打开：

```bash
open punchprint_ui/index.html
```

界面支持：

- 以打印平台尺寸为背景。
- 鼠标拖拽绘制外框。
- 支持三种外框绘制方式：矩形拖拽、自由手绘闭合线、多边形点选闭合。
- 矩形拖拽生成的是持久图形，和圆形、三角形、六边形一样可以选中、编辑、并集和导出。
- 双击空白处清空绘制内容。
- 也可以用“清空画板”按钮清空绘制内容。
- 可放置圆形、三角形、六边形基础图形；点击图形按钮后，在画布上按住拖动决定大小，按下点会作为图形边缘而不是中心。放置时不会根据拖拽方向旋转。
- 点击已放置的图形可以选中；圆形拖动边缘手柄调大小，三角形/六边形拖动顶点手柄调大小和方向。
- 点击图形内部并拖动可以移动图形位置；选中图形后按 `Delete` 或 `Backspace` 可以删除。
- 已放置图形可以指定材料 1-4，对应 `T0-T3`。当前版本会在 JSON 和 G-code 注释中保留材料映射；真正的多材料打印还需要按材料区域拆分 toolpath。
- 多个形状重合时按并集合并生成网格，矩形、圆形、三角形、六边形和自由多边形都会参与并集显示。
- 基础图形的原始边界用淡色虚线显示，整体并集外边界用更粗的实线显示，方便判断重叠区域。
- 导出 G-code 时，重叠图形之间的内部编辑边界不会作为外框打印；单材料区域按一整块并集处理。多材料边界需要后续按材料拆分 toolpath 时再保留。
- 底板厚度会参与 G-code 层数生成：层数按 `ceil(底板厚度 / 层高)` 计算，并逐层重复打印 PunchPrint 线网和外框。为了保留 EPI 方孔结构，当前不会用实体填充把孔填死。
- 调整打印机/平台参数、层高、底板厚度、EPI、网格线道数、框圈数、框线中心距、工具头和温度。
- 实时预览横竖网格。
- 下载参数 JSON。
- 下载 Snapmaker-Orca 风格 G-code。

多边形点选模式下，单击添加顶点；右键结束并闭合多边形。闭合后可以拖动顶点调整位置。

默认 G-code 使用：

- `M83` 相对挤出。
- Snapmaker-Orca 风格启动/结束宏。
- 初始框 -> 横向网格 -> 竖向网格 -> 最终框。
- 横向网格使用设置层高，竖向网格和最终框使用 175% 层高与额外 1.2 倍交叉流量。

## 参数含义

- 喷嘴直径：打印机硬件参数，用于判断单道打印线宽是否处在建议范围。
- 单道打印线宽：一根实际挤出线的宽度。默认 `0.4 mm`，通常应接近喷嘴直径，建议范围约为喷嘴直径的 `0.75-1.5` 倍，且不应小于层高。
- 层高：切片/打印层高，默认 `0.2 mm`。示例 Snapmaker Orca G-code 的普通层也是 `layer_height = 0.2`，第一层高度为 `0.250`。
- 底板厚度：目标 PunchPrint 底板的整体厚度。导出 G-code 会根据层高生成对应层数，并逐层打印 PunchPrint 线网/外框。
- 挤出流量倍率：整体挤出量修正系数。G-code 中每条线的挤出量按 `线长 x 单道打印线宽 x 层高 x 挤出流量倍率` 计算。层高保持不变，流量倍率增大会让实际走线更宽或更饱满。
- 网格线道数：一条设计网格线由几根实际挤出线并排组成。网格线宽 = 单道打印线宽 x 网格线道数，例如 `0.4 mm x 2 = 0.8 mm`。导出的 G-code 会真的生成两根并行线，而不是一根 0.8 mm 的假粗线。
- 框线中心距：多圈外框之间的中心线距离。它等于单道打印线宽时，相邻框线理论上刚好贴合；大于单道打印线宽时，中间会留空；小于单道打印线宽时，相邻框线会有重叠。
