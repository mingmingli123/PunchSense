先定义材料区域，再生成对应颜色的 EPI 网格和 G-code。

TPU 蛇形线

流程

第 1 阶段只显示纯色材料区域；第 2 阶段显示按材料着色的 EPI 网格。

材料区域

关闭区域点选时修改整个图形；打开后点击由边界包裹的小区域，可给重叠区域单独指定材料。

SVG 导入/保存：等待文件。SVG 支持闭合轮廓；红色开放线会作为 T0 蛇形 guide，黑色闭合轮廓会作为 T0 区域。

网格

外框固定使用白色 TPU / T2，沿整体外边界生成；设为 0 则不额外生成外框。

当前 G-code 不会额外生成 T3 PLA 外框。

网格线宽 = 单道打印线宽 x 线道数；交界重叠会按层交替把材料分界线向另一侧偏移。

TPU 蛇形：未开启。开启后可新增多条 T0 区域之间的蛇形线。

打印机/平台

建议范围约为喷嘴直径的 0.75-1.5 倍，且不要小于层高。

参考 tenis keychain v2.gcode：首层 0.25 mm，之后普通层 0.2 mm；实际厚度由层数和层高计算。
